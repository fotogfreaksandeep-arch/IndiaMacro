# IndiaMacro 0.2.0 local release candidate

IndiaMacro provides auditable programmatic access to official Indian
macroeconomic data. Its current scope is one RBI dataset: Sectoral Deployment
of Bank Credit from RBI Bulletin Current Statistics Tables 15 and 16. The
charting example is a downstream demonstration; data access and provenance are
the primary product.

Version 0.2.0 adds the public historical API:

```python
from indiamacro import rbi

history = rbi.sectoral_credit_history("2025-07", "2026-06")
points = history.select(
    series_id="RBI.SECTION42.NON_FOOD_CREDIT.OUTSTANDING",
    view="current",
)
resolved = history.resolve(policy="latest_publication", as_of="2026-03-31")
```

Historical support is verified only for the 12 RBI Bulletin issues from July
2025 through June 2026. The January 2026 issue uses the last-reporting-Friday
date basis; February 2026 changes current values to calendar month-end while
prior-year comparisons retain RBI's documented reporting-fortnight convention.
Continuous publication does not imply unchanged methodology.

## Local installation

Version 0.2.0 has not been published to PyPI. From a local source checkout:

```bash
python -m pip install .
```

After retained artifacts are built, install the exact local wheel with:

```bash
python -m pip install ./dist/indiamacro-0.2.0-py3-none-any.whl
```

Plotting is optional:

```bash
python -m pip install ".[plot]"
# or, from the retained wheel:
python -m pip install "./dist/indiamacro-0.2.0-py3-none-any.whl[plot]"
```

## Minimal chart example

```python
figure, axes = rbi.plot_sectoral_credit_history(
    history,
    outstanding_series_id="RBI.SECTION42.NON_FOOD_CREDIT.OUTSTANDING",
    growth_series_id="RBI.SECTION42.NON_FOOD_CREDIT.YOY_GROWTH_REPORTED",
)
figure.savefig("non_food_credit.svg")
```

## Known limitations

- This is not complete RBI sectoral-credit history.
- Dates before July 2025 and after June 2026 are unsupported.
- IndiaMacro does not yet provide DBIE access, other RBI datasets, automatic
  future-layout adaptation, dashboards, forecasting, or investment guidance.
- Live retrieval remains subject to the official RBI route being available.
- The release candidate is local only: no PyPI package, GitHub release, or
  `v0.2.0` tag has been created.
